# Diamond Decorations — sajt

Statički sajt, spreman za hostovanje na GitHub Pages.

## Sadržaj
- `index.html` — glavna stranica
- `utisci.html` — stranica sa svim utiscima
- Sve slike, fontovi i skripte su ugrađeni u same HTML fajlove (self-contained, ne treba dodatni folder sa slikama).

## Hostovanje na GitHub Pages
1. Napravi novi repozitorijum na GitHub-u (npr. `diamond-decorations`).
2. Ubaci `index.html` i `utisci.html` u koren repozitorijuma.
3. **Settings → Pages**.
4. Pod **Source** izaberi granu (npr. `main`) i folder `/ (root)`, pa **Save**.
5. Sajt će za par minuta biti na `https://<korisnicko-ime>.github.io/<repo>/`.

Za sopstveni domen: **Settings → Pages → Custom domain**.

## Navigacija
- „Vidi više utisaka" → `utisci.html`
- „← Nazad na sajt" i CTA na strani utisaka → `index.html`

## Mobilna verzija
Obe strane su optimizovane za telefon: plutajuća nav „ostrvo" se skuplje na manjim ekranima,
galerija i Instagram sekcija se listaju prstom, usluge i utisci se preslažu u jednu kolonu.
